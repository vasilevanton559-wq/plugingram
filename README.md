# Plugingram

**Статус: pre-beta**

Неофициальный Telegram-клиент для Windows на базе [Telegram Desktop](https://github.com/telegramdesktop/tdesktop) 7.0.9.

Не связан с Telegram Messenger LLP.  
Лицензия: GPLv3 + OpenSSL exception (`LEGAL`, `LICENSE`).

Канал: [@plugingram_official](https://t.me/plugingram_official)

---

## Скачать

Готовые сборки для Windows x64 публикуются в [Releases](../../releases).

1. Скачай `Plugingram-pre-beta-*-win64.zip`
2. Запусти `Plugingram.exe`
3. При первом запуске клиент установится в  
   `%AppData%\Roaming\Plugingram Desktop\`  
   и создаст ярлык на рабочем столе

Windows может показать предупреждение SmartScreen (сборка без цифровой подписи):  
**Подробнее → Выполнить всё равно**.

## Что умеет

### Обычный Telegram Desktop
Чаты, группы, каналы, медиа, звонки, папки, темы, несколько аккаунтов и остальной базовый функционал Telegram Desktop 7.0.9.

### Плагины
Раздел **Настройки → Плагины**:
- установка плагинов из Store (GitHub topic `plugingram-plugin`)
- включение / выключение
- обновление и удаление

Плагины работают в песочнице и не получают доступ к сообщениям, аккаунту и сети.

### Встроенный плагин Noise
Скрывает номера телефонов и коды в профилях шумом-спойлером.  
По клику значение можно показать.

### Поддержать создателя
В настройках есть кнопка поддержки через ЮMoney.

### Diagnostics
`Ctrl+Shift+I` — служебный оверлей: версия, память, сессия, плагины, логи.
